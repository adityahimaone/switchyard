This catches Tailwind/PostCSS compile failures that a clean typecheck misses. Confidence: 0.85
- `agent-browser` **is** available for visual verification. Install with `npm i -g --allow-scripts=agent-browser agent-browser` — a plain `npm i -g agent-browser` skips the postinstall, so no browser binary lands — then `agent-browser install` to download Chrome. Check `agent-browser --version` before assuming it is unavailable. Confidence: 0.9
- `agent-browser` subcommands worth knowing: `open <url>`, `reload`, `screenshot <path>`, `eval "<js>"`, `a11y` (runs axe-core against the live page), `press <Key>`, `find first "<sel>" hover`, `fill "<sel>" <value>`, `click "<sel>"`, `snapshot -i` (interactive-only accessibility snapshot that prints numbered element refs), `click @e10` (click a ref from the snapshot), `wait --url "<glob>"`, `skills get core`. Args are bare positionals — `screenshot --path` is wrong. Confidence: 0.85
- `agent-browser` text-based selectors fail silently against buttons whose label is composed of an icon plus nested text (`click "text=Add provider"` and `click "button:has-text('Add provider')"` both no-op'd). Fall back in this order: `snapshot -i` → read the `@eN` ref → `agent-browser click @eN`. Reaching for the snapshot immediately is faster than re-phrasing the selector. Confidence: 0.85
- `agent-browser` parses a backslash in a path as a selector. Pass Windows paths with forward slashes: `./.scratch/shot.png`. Confidence: 0.85

Distinguish the two by checking a fresh `pnpm build` artifact in `dist/assets/*.css`; if that is correct, kill the server, `Remove-Item -Recurse -Force node_modules\.vite`, restart, and re-fetch the CSS
