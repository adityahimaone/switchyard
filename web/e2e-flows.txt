# Flow-owning paths.
#
# A change to any of these escalates the Switchyard verify gate from `ui` to
# `e2e`, because the file owns a user-visible flow rather than a single surface.
# Everything else under web/src/ is routed on the `ui` ladder alone.
#
# This list exists because a path prefix cannot see every way a flow breaks. A
# shared hook can change click behaviour, a provider can change routing, a lib
# can change what a role resolves to — none of that touches a flow directory.
# When a flow breaks without a path change, add the owning path here.
#
# One path per line. Blank lines and lines starting with # are ignored.
# Consumed by the verify router in Switchyard (docs/specs/2026-10-04-design-quality-loop.md §3.3).

# --- auth: the gate everything else sits behind --------------------------------

web/src/components/auth/
